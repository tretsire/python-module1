# Вариант 6. Банковский вклад

## Описание

Консольная программа для расчёта банковского вклада с ежегодным начислением процентов.

Программа запрашивает:
- Первоначальную сумму вклада.
- Годовую процентную ставку.
- Срок вклада от 1 до 5 лет.

После этого рассчитывает начисленные проценты за каждый год, конечную сумму и общий доход.

- Переменные и типы данных.
- Ввод данных: `input()`.
- Преобразование типов: `int()`, `float()`.
- Арифметические операторы.
- Условия: `if`, `elif`, `else`.
- Логические операторы: `and`, `or`.
- Циклы: `for`, `while`.
- Функции и `return`.
- Форматирование строк: f-строки.

## Запуск программы

Для запуска необходим Python 3.

1. Скачайте или клонируйте репозиторий.
2. Откройте терминал в папке проекта.
3. Выполните команду:

```bash
python src/main.py
```

## Переменные

Глобальная константа:
- `TITLE_WIDTH` — ширина заголовков программы.

Основные локальные переменные:
- `amount` — первоначальная сумма.
- `rate` — процентная ставка.
- `years` — срок вклада.
- `category` — категория ставки.
- `current_amount` — текущая сумма вклада.
- `interest` — начисленные проценты.
- `final_amount` — конечная сумма.
- `income` — общий доход.
- `repeat` — повторный запуск программы.
